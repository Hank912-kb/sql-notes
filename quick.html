Find the key Exam 1 Q3 (2)

R = (A, B, C, D, E)   F = {AC → B, B → D, D → E}

  1. Never on a right side → in every key: A, C 沒人能推出它
  2. Derive everything: AC → B → D → E ✔ all of R
  3. Minimal? A alone ✘, C alone ✘ → yes
  4. Second key? Only if some FD points back into the key
  5. Write: K = (A, C) · prime A, C · nonprime B, D, E

How to write the derivation

AC → B and B → D, so AC → D   (transitivity)
B → D and D → E, so B → E     (transitivity)
AC → BDE                      (union)
AC → ABCDE, minimal key K1 = (A, C)

One line per step, rule name on each line. 每行寫規則名

Vocabulary

Superkeydetermines all of R 能決定全部

Minimal keynothing can be removed 不能再少

Primary keythe one you pick

  • Other minimal keys = candidate keys.
  • Prime = in at least one key. Nonprime = in none.

Traps keys

  • Not minimal: if (A, B) already works, (A, B, D) is not a key.
  • Missed second key: F = {A → BCDE, B → A} → keys are A and B.
  • Wrong keys → wrong prime list → every NF test wrong.

Answer sentences fill the blanks

Minimal key = (A, B).  Nonprime: C, D.

Not in 2NF: nonprime C depends on a part
(A) of the key (A, B).  FD: A → C.

In 2NF: no nonprime attribute depends on
a part of a key.
Not in 3NF: D is transitively dependent
on the key:  A → B and B → D.

In 3NF: right side B of C → B is prime.
Not in BCNF: C is not a superkey.

The highest normal form is 2NF.

Tracing T1 / T2 Exam 2 Q6

  1. UPDATE locks the row until COMMIT.
  2. Second UPDATE on that row waits.
  3. READ COMMITTED reads the latest committed value.
  4. SERIALIZABLE: row changed by a later commit → can't serialize, aborted.
